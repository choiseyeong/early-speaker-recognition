# Early Speaker Recognition 🗣️🔎

딥러닝 파이프라인을 처음부터 끝까지 직접 구현해보기 위한 학습 프로젝트이다. 실제 음성 데이터셋을 직접 넣어 EDA, 전처리, 모델 학습, 결과 도출까지 전 과정을 손으로 구현하고, 각 단계에서 일어나는 일을 직접 공부하는 것이 목적이었다. 딥러닝을 이 정도 깊이로 처음부터 끝까지 실행해본 것은 이 프로젝트가 처음이다.

---

짧은 발화만으로 화자를 구분할 수 있는가?

이 프로젝트는 **발화 초반 0.5초 ~ 1.5초**만으로 화자를 식별하는 실험이다. 입력 길이가 짧아질수록 정확도가 얼마나 떨어지는지, 세 가지 모델(X-Vector, ECAPA-TDNN, ResNet34-SE)을 비교해 분석한다.

---

## 결과 요약

테스트셋(화자 48명) 기준 duration별 분류 정확도

| duration | X-Vector | ECAPA-TDNN | ResNet34-SE |
|----------|----------|------------|-------------|
| 0.5초    | 80.8%    | 88.7%      | 84.3%       |
| 1.0초    | 89.7%    | 94.2%      | 91.0%       |
| 1.5초    | 92.0%    | **96.4%**  | 94.3%       |
| full     | 92.1%    | 95.8%      | 94.6%       |

- ECAPA-TDNN이 전 구간에서 가장 높은 정확도를 기록한다.
- 1.5초 이후 정확도 향상이 거의 없다. 화자 구분에 필요한 핵심 정보는 발화 초반 1.5초 안에 집중되어 있다.
- 0.5초에서도 80% 이상의 정확도가 나온다. 짧은 발화로도 화자 구분이 가능하다.


## 앞으로 보완하고 싶은 점

- **유사도 기반 평가 방식으로 전환**: 현재는 학습 때 본 48명 중 누구인지 맞히는 분류 헤드 방식으로 평가한다. 실제 화자 인증 시나리오에서는 두 음성이 같은 사람인지 판별하는 것이 목적이므로, 두 음성의 임베딩 벡터 간 코사인 유사도를 계산하는 방식으로 전환하고 EER(Equal Error Rate)로 평가하는 것이 더 적합하다. 따라서 실제 방식에 가깝게 EER 방식으로 평가를 진행해보고 싶다.
- **가상 음성 보안 시스템 구현**: 마이크로 음성을 입력받아 등록된 화자인지 실시간으로 판별하는 가상 보안 시스템 데모를 구현해보고 싶다.
