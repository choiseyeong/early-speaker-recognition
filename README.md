# Early Speaker Recognition 🗣️🔎
> "짧은 발화만으로 화자를 구분할 수 있는가?"

## 프로젝트 목적과 소개

이 프로젝트는 딥러닝 파이프라인을 EDA부터 전처리, 모델 학습, 결과 도출까지 전 과정을 직접 구현해보며<br/>
각 단계에서 일어나는 일들을 공부해보는 것을 목적으로 한다.

이 프로젝트는 **발화 초반 0.5초 ~ 1.5초**만으로 화자를 식별하는 실험이다.<br/>
입력 길이가 짧아질수록 정확도가 얼마나 떨어지는지,<br/>
세 가지 모델(X-Vector, ECAPA-TDNN, ResNet34-SE)을 비교해 분석한다.

---

## 결과 요약

48명의 화자 테스트셋 기준 duration별 분류 정확도

| duration | X-Vector | ECAPA-TDNN | ResNet34-SE |
|----------|----------|------------|-------------|
| 0.5초    | 78.0%    | 86.2%      | **89.1%**   |
| 1.0초    | 89.3%    | **94.7%**  | 94.2%       |
| 1.5초    | 92.6%    | 95.6%      | **96.3%**   |
| full     | 94.2%    | 96.5%      | **97.6%**   |

- ResNet34-SE가 0.5초·1.5초·full 구간에서 가장 높은 정확도를 기록한다. ECAPA-TDNN은 1.0초 구간에서 근소하게 앞선다.
- full이 1.5초 대비 모든 모델에서 1~1.6%p 향상된다. 발화 초반 1.5초 이후 구간도 실질적인 정보를 추가한다.
- 0.5초에서도 모든 모델이 78% 이상의 정확도를 달성한다. 아주 짧은 발화로도 화자 구분이 가능하다.

## 앞으로 보완하고 싶은 점

- **유사도 기반 평가 방식으로의 전환**<br/>
현재 프로젝트는 학습에 사용된 48명 중 입력 음성이 누구의 것인지 맞히는 분류 헤드 방식으로 평가한다.<br/>
하지만 실제 화자 인증 시나리오에서는 특정 음성이 “누구인지”를 분류하는 것보다, 두 음성이 같은 사람인지 판별하는 것이 더 중요하다.<br/>
따라서 음성에서 추출한 임베딩 벡터 간 코사인 유사도를 계산하고, 이를 기반으로 EER(Equal Error Rate) 지표를 활용하는 방식으로 평가를 확장해보고 싶다.
- **가상 음성 보안 시스템 구현**<br/>
마이크로 음성을 입력받아 등록된 화자인지 실시간으로 판별하는 가상 음성 보안 시스템 데모를 구현해보고 싶다.<br/>
이 시스템에서는 사전에 등록된 화자의 음성 임베딩을 저장해두고, 사용자가 입력한 음성의 임베딩과 비교하여 인증 여부를 결정한다.<br/>
이를 통해 새로운 사용자를 추가할 때 모델을 다시 학습하지 않고도, 등록 음성의 임베딩만 추가하여 확장 가능한 구조를 실험해볼 수 있다.
